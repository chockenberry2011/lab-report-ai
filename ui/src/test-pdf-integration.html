Usage

The PDF viewer is now integrated into the ReviewEditorPage. Users can:

  1. Toggle PDF viewer on/off with the "Show/Hide PDF" button
  2. View original lab reports side-by-side with the review form
  3. See confidence-based highlighting of extracted fields
  4. Click between form and PDF to synchronize field focus
  5. Use keyboard shortcuts (Cmd+[ / Cmd+]) to hide/show panels
  6. Resize panels by dragging the divider
